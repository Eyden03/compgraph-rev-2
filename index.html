Glossary & quick reference

Module 5

VBO: GPU/server-memory storage for vertex data. The common sequence is generate, bind, upload, enable client state, set pointer, draw, disable, unbind, delete.

Targets: GL_ARRAY_BUFFER stores vertex attributes; GL_ELEMENT_ARRAY_BUFFER stores indices.

Usage hints: STATIC = set once/use many; DYNAMIC = change repeatedly/use many; STREAM = set once/use only a few times.

Mapping: glMapBuffer exposes buffer memory to the client; always call glUnmapBuffer after edits.

Module 6

Matrix indices: (i,j) means row i, column j. Addition/subtraction require identical dimensions.

Homogeneous w: w=1 represents a position, so translation affects it; w=0 represents a direction, so translation does not.

Transforms: translation adds offsets, scaling multiplies components, and rotation mixes coordinates using sine/cosine. Order matters when matrices are combined.

Combined buffer: reserve total storage with glBufferData(..., NULL,...), fill blocks using glBufferSubData, and point attribute readers at byte offsets.
